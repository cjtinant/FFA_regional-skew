# 📁 Project Documentation (`notes/`)

------------------------------------------------------------------------

## 📚 Folder Purpose

The `notes/` directory serves as a centralized archive for:

- Meeting notes
- Brainstorming ideas
- Modeling thoughts (“why didn’t ridge work here?”)
- Paper/article annotations
- Planning diagrams
- Unpublished exploratory code chunks
- Zettelkasten-style markdown

------------------------------------------------------------------------

## 🗂️ Subfolders

The `data/` folder is organized as follows:

``` plaintext

notes/
    ├── to_process           # notes in docx doc format to incorporate in future
```
